# 2026-06-25 - Path To 10 Hardening

## Summary

The local simulation agent was hardened for open-source testing and team use. The work focused on safer chat persistence, clearer training scenarios, shorter persona conversations, stronger accessibility and a more maintainable Nuxt UI structure.

## Changes

- Added 10 concrete training cards for common leadership and team situations.
- Adjusted persona chat so responses stay short and coach feedback appears after 10 interactions or on demand.
- Made chat-turn persistence atomic so failed model calls do not leave partial user turns in SQLite.
- Split the root Nuxt UI into focused simulation components.
- Moved simulation presets, templates, phrase library and coach cadence into composables.
- Added tests for chat persistence, training context and coach cadence.
- Added Swiss German page language, skip link, visible focus styles and labelled form controls.
- Added baseline security headers through Nuxt route rules.
- Prepared open-source project files including README, license, contribution and security guidance.

## Notes

- The app still depends on a local Ollama service and a locally available model.
- `.agents/` remains intentionally ignored because it is local agent workspace configuration.
- The production build currently emits a Nuxt/Vite sourcemap warning from `nuxt:module-preload-polyfill`; the build completes successfully.

# Code of Conduct

Dieses Projekt soll ein sachlicher, respektvoller Ort fuer Zusammenarbeit sein.

## Erwartetes Verhalten

- Respektvoll und konstruktiv kommunizieren.
- Kritik an Code, Text oder Produktentscheidungen festmachen, nicht an Personen.
- Unterschiedliche Erfahrungsstaende beruecksichtigen.
- Fehler als Teil der Arbeit behandeln.

## Nicht akzeptiertes Verhalten

- Beleidigungen, Belaestigung oder abwertende Kommentare.
- Diskriminierende Sprache.
- Veroeffentlichung privater Informationen anderer Personen.
- Wiederholtes Stoeren von Diskussionen oder Reviews.

## Durchsetzung

Maintainerinnen und Maintainer koennen Beitraege moderieren, Issues schliessen oder Personen vom Projekt ausschliessen, wenn dieses Verhalten verletzt wird.
